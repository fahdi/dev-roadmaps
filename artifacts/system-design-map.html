System Design Map

Twelve designs worth knowing cold, and the one thing each is really testing. Most of them are the same handful of ideas wearing different clothes, which is why memorising answers works far worse than recognising the pattern.

Core primitives

01URL Shortener

Short IDs mapped to long URLs, with the hot links cached. The real question is ID generation without collisions.

base62, 301 vs 302
02Rate Limiter

Token bucket per user, and the hard part is staying fair across many servers rather than per instance.

Redis counters, 100 per minute
03Key-Value Store

Consistent hashing to place keys, replication plus quorum to survive nodes disappearing.

Dynamo-style, R + W > N
04Distributed Cache

Eviction and invalidation, and above all avoiding the stampede when a hot key expires at once.

LRU, TTL, single-flight

Scale and delivery

05Chat / Messaging

Persistent connections plus ordering. Delivery guarantees are the interesting part, not the socket.

WebSockets, sequence numbers
06News Feed

Fan-out on write or on read, and the celebrity problem that breaks whichever one you picked.

push vs pull, hybrid
07Video Streaming

Transcode once into many renditions, serve from a CDN, adapt bitrate to the viewer's connection.

HLS, DASH, edge caching
08Ride-Share Matching

Geospatial indexing so you can find nearby drivers fast, then match without double-booking.

geohash, quadtree

AI systems

09AI Chat + RAG

Retrieve first, then answer. Route by task, stream tokens back, and cite what you used.

retrieve, route, stream, cite
10LLM Inference

Dynamic batching to keep GPUs busy, and a KV cache so each new token does not re-read the whole conversation. That cache grows with context and never shrinks mid-generation, so it is a memory ceiling as much as an optimisation.

batching, KV cache growth, GPU scheduling
11Enterprise RAG

Ingestion plus hybrid search, reranking, and access control that survives the retrieval step.

hybrid search, rerank, permissions
12Agentic AI

Tool calls inside a loop, with memory, retries, approvals and a way to stop.

loop, memory, approvals, safety
Twelve designs, far fewer actual ideas.
Caching, partitioning, replication, queueing and fan-out show up in nearly all of them.
Learn to spot which of those a question is really about and the unfamiliar prompts stop being unfamiliar.
Roadmap: get the core primitives solid, then the delivery patterns built on them, then the AI systems that reuse both.
