10 Interview Patterns, Animated

Most interview problems are one of a small number of shapes wearing different words. Each card runs its own mechanic on a loop, and names the signal in the question that should make you reach for it.

Recognising the shape is the skill. The code is the easy part.
Nobody solves these by recalling a solution. They read the constraints, spot which of these shapes fits, and then write something they have written many times before.
If a problem mentions a sorted array, a contiguous run, a shortest path or a repeated subproblem, it has already told you which one to use.
Roadmap: learn the mechanic, learn the signal that selects it, then practise mapping unfamiliar wording onto a shape you already know.
