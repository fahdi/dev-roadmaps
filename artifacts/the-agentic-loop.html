The Agentic Loop

A coding agent does not answer once and stop. Your prompt starts the work, tools keep it moving, and the loop runs until the task is genuinely done or you step in.

01

Gather Context

  • Search files for what is relevant
  • Read the code that matters
  • Understand the current state before changing it
02

Take Action

  • Edit files
  • Run commands
  • Use tools to make the change real
03

Verify Results

  • Run the tests
  • Inspect the actual output
  • Check that the fix is a fix
Verified and correct → task complete Something is off → back to gather context

Tools power every phase

The loop is only as capable as what it can reach

Not a fire-and-forget button. The best results come from steering mid-run

New information informs the next decision.
That single property is what separates a loop from a long answer.
An agent that acts without verifying is guessing at scale, and an agent that verifies without looping back just reports the problem instead of fixing it.
Roadmap: gather context, take action, verify, then either finish or go round again with what you learned.
Pairs with 6 Levels of Agentic AI, where this loop is level 6, and Design Your Agent's Control Plane for shaping how the agent behaves inside it.
