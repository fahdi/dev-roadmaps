The Same Pipeline, as Five Moves

RAG sounds like fifteen scary buzzwords. Every one of them is part of one of five moves — learn the patterns, not the jargon.

Splitone → many
Parsingread files into clean text
Chunkingbreak text into passages
Tokenizationtext → model tokens
Searchnearest neighbours
Embeddingstext → vectors of meaning
Vector DBstore & search vectors
Retrieverfetch relevant chunks
Composeblocks → one prompt
Prompt Templateslot context into a prompt
Groundinganswer from real facts
Context Windowwhat the model can hold
Filtersort · rank · pick
Top-Kkeep the K best hits
Re-rankingreorder by true relevance
Hybrid Searchkeyword + vector search
Productionloops · scores · cache
Cachereuse answers, cut cost
Evaluationscore answer quality
Hallucinationcatch made-up answers

Index first — everything above the query line happens before a user ever asks. Then retrieve → augment → generate → verify.

Roadmap: Load → Chunk → Embed & Tag → Index → Retrieve → Augment → Generate → Verify → Evaluate (and iterate)
